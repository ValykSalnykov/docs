## Что делает сервис

AI Invoice помогает загрузить накладную или чек, распознать данные и подготовить входящую накладную для Syrve. Ответственный пользователь сверяет результат с оригиналом, исправляет ошибки, сохраняет проверенную версию и отправляет её в Syrve.

## Основной сценарий

1. Сотрудник загружает документ через Web или Telegram.
2. Система сохраняет оригинал и обрабатывает его в очереди с помощью OCR и AI.
3. Ответственный пользователь проверяет поля и товары рядом с исходным файлом.
4. После сохранения проверенной версии документ можно отправить в Syrve.

Непроверенный результат автоматически в Syrve не отправляется.
