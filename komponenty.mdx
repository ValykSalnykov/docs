# Компоненты Mintlify

Эта страница показывает способы подачи одного и того же материала. Примеры описывают реальный поток AI Invoice, но не выполняют операции с документами.

<Info>
  Распознанный результат становится рабочей накладной только после проверки человеком.
</Info>

<Warning>
  Dev seed используется только локально. Его нельзя запускать на базе с данными клиентов.
</Warning>

## Шаги

<Steps>
  <Step title="Загрузить">
    Добавьте накладную через Web или Telegram.
  </Step>
  <Step title="Проверить">
    Сверьте реквизиты и строки с исходным файлом.
  </Step>
  <Step title="Отправить">
    После сохранения проверенной версии отправьте в Syrve.
  </Step>
</Steps>

## Вкладки

<Tabs>
  <Tab title="Пользователь">
    Следит за обработкой загруженных документов.
  </Tab>
  <Tab title="Администратор">
    Исправляет данные и подтверждает отправку в Syrve.
  </Tab>
  <Tab title="Разработчик">
    Поднимает API и worker локально, проверяет контракты.
  </Tab>
</Tabs>

## Раскрывающиеся ответы

<AccordionGroup>
  <Accordion title="Можно ли отправить непроверенный OCR-результат?">
    Нет. Сначала сохраняется проверенная версия документа.
  </Accordion>

  <Accordion title="Где хранится оригинал?">
    Оригинальный загруженный файл сохраняется в MinIO.
  </Accordion>
</AccordionGroup>
