# Возможности Mintlify на примере AI Invoice

Эта документация создана как демонстрационный стенд. Содержание основано на текущем репозитории AI Invoice; интерактивные функции Mintlify можно проверить прямо на опубликованном сайте.

<Warning>
  Раздел API использует локальный адрес `http://localhost:3001/api`. Не вводите реальные токены в публичный playground.
</Warning>

## Чек-лист для просмотра

<Steps>
  <Step title="Навигация">
    Переключите вкладки «Руководство» и «API», раскройте группы в боковом меню.
  </Step>
  <Step title="Поиск">
    Найдите «накладной» через поиск в верхней части сайта.
  </Step>
  <Step title="AI-помощник">
    Задайте вопрос по опубликованным страницам через Ask AI.
  </Step>
  <Step title="Интерактивный контент">
    Откройте вкладки и аккордеоны на странице компонентов, скопируйте команду запуска.
  </Step>
  <Step title="API">
    Посмотрите схему запроса, пример ответа и переключение языка кода на страницах эндпоинтов.
  </Step>
  <Step title="Оформление">
    Переключите светлую и тёмную темы; проверьте адаптивное меню на узком окне.
  </Step>
</Steps>

## Что пока не настроено

| Возможность | Состояние в этом демо |
| --- | --- |
| Свой домен и логотип | Требуют отдельной настройки брендинга и DNS |
| GitHub-синхронизация | Веб-редактор используется как тестовая песочница; репозиторий проекта не менялся |
| Production API | Намеренно не подключён к интерактивному playground |
| Аналитика и обратная связь | Можно подключить после выбора рабочего сайта и политики данных |
| Версии и локализации | Полезны после утверждения структуры реальной документации |

<Info>
  Это демонстрация возможностей, а не полный официальный справочник Mintlify. Доступность функций зависит от тарифа и конфигурации сайта.
</Info>
