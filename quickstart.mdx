## Требования

- Node.js 24 и pnpm 11.7.0 через Corepack.
- Docker Compose.
- Доступ к действительным ключам Azure Document Intelligence и OpenAI для реального распознавания.

## Подготовка

Из корня репозитория создайте локальные файлы окружения из шаблонов и заполните нужные значения. Не публикуйте `.env` и ключи.

```bash
cp infra/.env.example infra/.env
cp packages/db/.env.example packages/db/.env
cp apps/api/.env.example apps/api/.env
cp apps/web/.env.example apps/web/.env.local
corepack enable
CI=true pnpm install
pnpm db:generate
pnpm local:infra
pnpm db:migrate
pnpm local:db:seed
pnpm dev:full
```

`local:infra` создаёт bucket `invoice-documents`. Dev seed предназначен только для локальной разработки; не запускайте его на данных клиентов или в production.

## Адреса

- Web: `http://localhost:3000`
- API: `http://localhost:3001/api`
- MinIO Console: `http://localhost:9001`

За полными настройками и диагностикой обращайтесь к `docs/local-development.md` и `docs/configuration.md` в репозитории.
