# Частые вопросы

<AccordionGroup>
  <Accordion title="Отправляется ли результат распознавания в Syrve автоматически?">
    Нет. Пользователь сверяет результат с оригиналом, сохраняет проверенную версию и отдельно запускает отправку.
  </Accordion>

  <Accordion title="Где хранится исходный файл?">
    Оригинал сохраняется в MinIO. Данные документа и история обработки хранятся в PostgreSQL.
  </Accordion>

  <Accordion title="Что делает фоновой worker?">
    Получает задачу из BullMQ, вызывает OCR/AI за интерфейсами провайдеров и записывает результат для проверки человеком.
  </Accordion>

  <Accordion title="Можно ли использовать этот сайт для реальных API-запросов?">
    В демо указан локальный API `http://localhost:3001/api`. Для защищённых маршрутов нужен локальный тестовый токен. Не вводите production-данные.
  </Accordion>
</AccordionGroup>
